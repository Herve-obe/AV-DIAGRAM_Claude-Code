# AV Diagram

Application web libre pour concevoir des synoptiques d'installations audiovisuelles professionnelles (concert, plateau TV, installation fixe) : blocs équipements, liaisons typées par signal, contrôle de compatibilité, listes de câblage, patch et nomenclature générées automatiquement.

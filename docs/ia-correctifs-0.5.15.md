# Reprise du câblage IA — 0.5.15

Le [banc réel Windows 0.5.14](https://github.com/Herve-obe/AV-DIAGRAM_Claude-Code/actions/runs/40320733166/job/121564702958) a réussi cinq essais sur six. La conférence a encore échoué : Qwen3 4B a demandé trois câbles pour chaque micro et deux pour chaque enceinte mono, puis a répété ce plan. Les règles ont refusé les câbles supplémentaires sans toucher au projet. Le cahier des charges interview/live et la réorganisation locale ont réussi.

Le diagnostic de capacité indique maintenant le nombre de câbles simulés pour une paire, le nombre demandé pour chaque paire et le total du flux. Il explique comment demander un seul câble par appareil, sans corriger silencieusement un flux stéréo ou une exigence réelle de plusieurs liaisons. Le paramètre lui-même décrit son défaut et les exemples micro, caméra, enceinte et enregistreur stéréo ; la consigne de construction reprend cette distinction.

Un test rejoue les deux erreurs successives, vérifie les messages, la correction en deux étapes, les six appareils et cinq câbles, ainsi que l’absence de modification du projet initial. Validation locale : 476 tests réussis, six essais réservés au vrai modèle ; types vérifiés. Le nouveau banc Qwen3 4B a réussi ses six essais réels sur Windows et ses six essais sur macOS dans le [run 40324896147](https://github.com/Herve-obe/AV-DIAGRAM_Claude-Code/actions/runs/40324896147). Cela valide ces scénarios, sans garantir toutes les formulations possibles. Le contrôle natif de fenêtre Windows a rencontré une course pendant l’animation de restauration ; il attend maintenant la géométrie attendue avant de conclure, avec le même délai maximal et la même tolérance de deux pixels.

Le [complément documentaire ManualsLib](inventaire/suite-manualslib-2026-10-26.md) contient le lot de fiches corrigées et les divergences qui empêchent leur validation.

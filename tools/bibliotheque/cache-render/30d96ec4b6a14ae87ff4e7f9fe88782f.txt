Creativity Made Simple

Advancements in digital signage requirements mean that customers demand greater freedom in creating and deploying small, medium and large scale signage projects.

The Datapath Fx4 is a multi-faceted stand alone display controller that supports a choice of inputs, high bandwidth loop-through as well as 4 genlocked outputs in either DisplayPort or HDMI.

The Fx4 features a DisplayPort1.2 main input alongside two HDMI1.4 inputs offering 4K 4096 x 2160p at 60fps. The intuitive user interface allows users to determine which input is used.






Unparalleled connectivity options

3 Input Choices
The Fx4 features a DisplayPort1.2 main input and two HDMI1.4 inputs. The intuitive UI allows users to determine which input is used.

Network Connectivity
Dual Ethernet ports allow users to add the device to their networks. Ethernet loop though support on the second port means only one device in the chain needs to be physically connected.

Genlocked Input
A dedicated BNC connector allows users to SYNC with third party hardware.

Loop Through
A dedicated DisplayPort1.2 loop through output allows users to link multiple devices. Specifically designed to prevent any loss of resolution, and the original capture signal remains unchanged.

Powered by Wall Designer

Wall Designer allows users to add displays from the ever expanding database of monitors, visualise their content by adding inputs, backgrounds and adjusting capture regions. Finally, you can instantly configure all Datapath Fx4’s either via USB or the network ports.

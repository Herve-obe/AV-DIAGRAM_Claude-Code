COLORado 2-Quad Zoom is a solid indoor/outdoor wash light featuring 14 bright quad-colored Osram (RGBW) LEDs and a 7° to 45° zoom. Selectable dimming curves facilitate its integration into an existing rig. This excellent LED wash light maintains its IP65 rating with IP rated DMX cables, but standard 5-pin XLR DMX cables work perfectly for indoor use. IP rated power and data connectors allow for easy connections without the need for proprietary cabling.

Features
Dynamic Color Mixing

Achieve a wide spectrum of colors with full RGBW mixing, adjustable either manually or through DMX control.

Versatile Zoom Control

Easily adjust the beam angle using either manual controls or DMX for precise lighting coverage.

Adjustable Color Temperature

Select from a wide range of color temperature presets, from a warm 3,200K to a cool 10,000K.

Onboard Automated Programs

Access built-in automatic and custom programs using DMX or Master/Slave mode for quick and easy light shows.

High-Resolution Dimming

Experience exceptionally smooth fades with 16-bit dimming control over individual colors and the master dimmer.

Selectable Dimming Curves

Choose from multiple dimming curves to achieve the perfect fade for any application, enhancing programming versatility.

Pre-Programmed Color Macros

Instantly access a variety of built-in color effects with adjustable speed for dynamic visual displays.

Flexible Mounting Options

The double-bracketed yoke allows for traditional truss mounting or can be used as a convenient floor stand.

All-Weather Connections

Operate reliably in any environment thanks to IP-rated power and DMX input and output connections.

Universal DMX Compatibility

Connect to any professional lighting system with both 3-pin and 5-pin DMX input and output connections.

Secure LED Display

Easily configure settings on the onboard LED display, which features password protection to prevent unauthorized changes.

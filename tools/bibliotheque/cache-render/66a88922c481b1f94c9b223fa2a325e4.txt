Twin-Iso Specifications

The Radial Twin-Iso is a line level isolator that employs two high performance Jensen® audio transformers. These are able to withstand tremendous signal levels without distortion. The Twin-Iso is basically a straight wire interface with some RF filtering to eliminate noise.

Specifications	
Audio circuit type:	Passive line-level isolation, transformer based
Transformer:	Jensen Transformer
Number of channels:	Stereo (dual mono)
Frequency response:	10Hz ~ 50KHz (± 1dB)
Dynamic range:	135dB
Total harmonic distortion:	0.001% @ 1kHz, +4dBu output
Phase Deviation:	0.5° @ 100Hz; 37° @ 20Hz
Input Impedance:	600Ω, balanced
Output Impedance:	600Ω, balanced
Maximum Input:	+21dBu @ 1kHz, 1% THD+N
Features
Ground lift
Input Connectors:	2 XLR-F inputs
Output Connectors:	2 XLR-M outputs
General
Conditions:	For use in dry locations only between 5°C and 40°C
Warranty:	Radial 3-year, transferable
